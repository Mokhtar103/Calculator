# 🧮 Calculator

A simple console-based calculator application built with C#.

The application allows the user to perform basic arithmetic operations and supports performing multiple calculations without restarting the application.

## ✨ Features

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`
- Input validation
- Prevents division by zero
- Perform multiple calculations without restarting the application

## 🛠️ Technologies Used

- C#
- .NET
- Console Application
- Visual Studio

## 🚀 How to Run

### Prerequisites

Make sure you have:

- .NET SDK installed
- Visual Studio or any C# compatible IDE

### Steps

1. Clone the repository:
git clone <your-repository-url>

2. Navigate to the project folder:
cd Calculator

3. Run the application:
dotnet run

Or simply open the project in Visual Studio and press:
Ctrl + F5
